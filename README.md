# 开口练习室

一个适配桌面与手机浏览器的中文表达训练单页应用。

## 功能

- 朗读复述的七类专项题目
- 自由话题练习题生成
- 练习计时、打卡、连续天数与成长记录
- SiliconFlow DeepSeek V4 Flash：生成练习题、分析表达、梳理目标
- 浏览器本地保存，不需要账号或后端服务

## 本地预览

直接用浏览器打开 `index.html`。

## 使用 AI 帮练

打开页面右上角的 AI 设置，输入你自己的 SiliconFlow API Key。密钥默认只在当前浏览器会话中保留；勾选“在此设备记住密钥”后会保存在本机浏览器。每个使用者需要配置自己的密钥，API 请求会由浏览器直接发送到 SiliconFlow。
